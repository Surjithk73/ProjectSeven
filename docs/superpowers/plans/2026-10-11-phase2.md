# Phase 2 implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development task-by-task. Steps use checkboxes for tracking.

**Goal:** Scan, compare and repair a supplied local Python Git repository in disposable jobs, retaining tested local patches and evidence.
**Architecture:** Explicit package configuration feeds commit-pinned workspaces, durable job storage and bounded command execution. The reusable engine has no dashboard state or demo paths; CLI and allowlisted dashboard jobs call it.
**Tech stack:** Python 3.11+, stdlib, Pydantic, existing google-genai/FastAPI dependencies, native oasdiff.
**Spec:** docs/superpowers/specs/2026-10-11-phase2-design.md; IMPLEMENTATION_PLAN.md Phase 2.

## Global constraints
- Local Git sources only in this phase; preserve both existing repositories and original source checkouts.
- No publishing, merging, automatic original edits, hosted sandbox claims or live inference in regression tests.
- Config version 1; defaults attempts 3, command timeout 120s, job timeout 600s, log limit 65536 bytes.
- Commands are argv lists; source paths resolve inside disposable workspace; protected tests/config/contracts may not be weakened.
- Controller credentials must not be forwarded to repository commands; explicit source/contract/evidence metadata must survive cleanup.

## Review focus
- Configs resolving a source outside the config directory must still pin the correct source commit and avoid writing artifacts inside it.
- Git tree symlinks, submodules and secret files must not escape or leak during snapshotting.
- Simultaneous jobs and late cancellation must not confuse one job's state with another.
- Repository commands that alter tests or candidate code must not manufacture validation evidence.
- Source URLs with multiple calls/dynamic expressions must yield accurate limitations, not guessed localization.

## Task 1: configuration, workspaces and job runtime
Files: apishield/__init__.py, configuration.py, workspace.py, jobs.py, commands.py; tests/test_local_runtime.py.
Interfaces:
- `load_config(path: str|Path) -> IntegrationConfig`; resolved `.repository`, `.base_spec`, `.target_spec` are Path, `.code_paths`, `.setup_commands`, `.test_commands`, `.environment`, `.budgets`, `.model`, `.use_intent`.
- `Budgets` fields max_attempts, command_timeout_seconds, job_timeout_seconds, output_limit_bytes.
- `JobStore(root: Path)`: `create(config, operation)->Job`, `get(job_id)->dict`, `cancel(job_id)->dict`, `list_jobs()->list[dict]`.
- `Job`: `.id`, `.path`, `.workspace`, `.config`, `.started_at` monotonic, `event(kind, **data)`, `finish(result:dict)->dict`, `cancelled()->bool`, `remaining()->float`, `check()->None` raises JobCancelled/JobTimedOut; `cleanup()`.
- `prepare_workspace(job)->dict` returns source_commit, dirty_source, excluded_files, base_spec_hash, target_spec_hash; copy contracts to job.path/contracts/base.json,target.json. No caller mutation.
- `run_command(argv:list[str], job:Job, label:str)->dict` keys exit_code, stdout, stderr, duration_seconds, timed_out, cancelled, output_limited; `sanitized_environment(config)->dict`.
- Exceptions JobCancelled and JobTimedOut exported by jobs module. `.finish` writes atomic result plus job_id/operation. Each process tree stopped before result return. No hidden cwd changes.
- [x] Write failing runtime tests for config validation, pinned snapshots with dirty originals, secrets/symlink/traversal, timeout/descendant/cancel and output limits.
- [x] Run focused tests to establish RED, implement minimal runtime, run GREEN.
- [x] Commit owned files; report paths/commands/results. Task review before next task.
