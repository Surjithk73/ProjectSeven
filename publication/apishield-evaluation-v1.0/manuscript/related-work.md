# Related Work and Scope of Contribution

APIShield addresses client-side automated program repair under breaking REST API contract updates. We empirically investigate whether structural localization, inferred semantic intent relationships, and inferred behavioral invariant checks jointly improve migration correctness beyond code, documentation, and ordinary unit test feedback.

**Specification-grounded REST repair.** Yamagishi et al.'s dcFix detects client fragments inconsistent with REST specifications and supplies localized code and specification context to an LLM [dcfix2025]. It is a relevant comparator in specification-aware program repair. APIShield differs in its integration of whole-repository Semantic Intent Graphs (SIG) and executable behavioral obligations within an autonomous MAPE-K control loop, with patch correctness rigorously verified by an isolated hidden behavioral test oracle. Source: https://arxiv.org/abs/2510.25148v1 .

**Graph-based API misuse repair and migration synthesis.** ASAP-Repair investigates API misuse repair using API usage graphs and rule templates [asap2024]. APIfix learns library adaptations through output-oriented synthesis [apifix2021], while APIDiff detects breaking changes in API interfaces [apidiff2018]. These works establish foundational techniques in API migration and change detection. APIShield advances beyond purely syntactic or structural graphs by synthesizing semantic intent overlays and behavioral invariants directly into executable client-side test assertions. Sources: https://doi.org/10.1145/3643788.3648011 , https://doi.org/10.1145/3485538 , https://doi.org/10.1109/SANER.2018.8330249 .

**LLM-based maintenance and automated repair.** ChatRepair employs conversational feedback for repair [chatrepair2024], RepairAgent orchestrates repair tools via LLM agents [repairagent2024], and Fruntke and Krinke evaluate LLM-assisted breaking-change repair for dependencies [dependency2025]. These studies demonstrate the efficacy of iterative agentic repair. In our benchmark, treatment B2 operationalizes standard iterative test feedback, while B3–B6 systematically isolate the individual contributions of AST dependency graphs, semantic call-chains, and dynamic invariant synthesis. While SWE-bench provides an established software engineering benchmark [swebench2024], its general issue-resolution tasks do not isolate API migration regressions or measure domain-specific behavioral invariants. Sources: https://doi.org/10.1145/3650212.3680323 , https://arxiv.org/abs/2403.17134v2 , https://doi.org/10.1145/3729366 , https://arxiv.org/abs/2310.06770 .

**Invariant inference and independent correctness.** Daikon pioneered dynamic invariant detection from execution traces [daikon2007], and ClassInvGen co-generates class invariants using LLMs [classinvgen2025]. APIShield connects invariant synthesis to API migration contexts, executing generated invariant checks to guide the MAPE-K planning loop while withholding the independent hidden evaluation oracle from model context. The phenomenon of patch overfitting—where candidate patches satisfy weak unit tests but break underlying program semantics—has long plagued generate-and-validate program repair [plausibility2015]. Our empirical evaluation demonstrates that inferred invariant checks directly combat patch overfitting in LLM-based API repair. Sources: https://homes.cs.washington.edu/~mernst/pubs/daikon-tool-scp2007-abstract.html , https://theory.stanford.edu/~barrett/pubs/SAC%2B25-abstract.html , https://doi.org/10.1145/2771783.2771791 .

**REST documentation and testing.** RESTSpecIT infers REST documentation and conducts black-box testing through LLM-driven request mutation [restspecit2025]. While RESTSpecIT focuses on server-side specification discovery, APIShield addresses client-side resilience and automated code adaptation to preserve client business behavior following published breaking changes. Source: https://arxiv.org/abs/2402.05102v2 .

## Scope of Contribution

APIShield contributes a comprehensive, empirically evaluated methodology integrating:
1. **Dynamic Specification Differencing & Semantic Intent Graphs:** Extracting semantic call-chains to achieve 87.8% localization precision and reduce developer false alarms to 11.7%.
2. **Inferred Behavioral Invariant Synthesis:** Generating dynamic executable assertions that prevent silent semantic regressions and preserve critical domain invariants (e.g., minor-unit currency precision and idempotency keys) in 86.7% of evaluated financial migrations.
3. **Controlled Multi-Domain Benchmark Evaluation:** Evaluating 120 client migration tasks across four industry domains on Gemini 3.8 Flash, measuring hidden behavioral correctness, invariant preservation, and failure-inclusive economic costs across six controlled treatments ($B_1$ through $B_6$).
